# FocusX — Focus Better. Achieve More

FocusX is a minimalist, modern productivity and study timer web application inspired by Apple design principles and premium SaaS dashboards. It helps students and professionals concentrate using structured focus intervals (Pomodoro technique), manage daily task items, and track study metrics seamlessly.

## ✨ Features

- **Precision Focus Timer:** Configurable countdown timer with Focus sessions, Short breaks, and Long breaks, utilizing timestamp validation for accuracy even when tabs are inactive.
- **Interactive Dashboard:** Live progress tracking towards daily goals, streak counters, and rotating motivational quotes.
- **Daily Study Planner:** Task manager allowing users to add tasks, assign subjects, check off completed items, and store items securely via `localStorage`.
- **Focus Ambience Synthesizer:** Built-in ambient sound generator (Rain, Forest, White noise) with real-time volume controls.
- **Detailed Statistics:** Cumulative focus tracking, session records, and daily reset management.
- **Customizable Preferences:** Modify timer durations, goals, sound alerts, and switch seamlessly between Dark and Light themes.

## 🛠️ Technology Stack

- **HTML5** (Semantic markup)
- **CSS3** (Variables, Flexbox/Grid layouts, custom responsive variables, smooth transitions)
- **Vanilla JavaScript** (ES6+ modular design, Web Audio API, `localStorage` state retention)
- **No frameworks or external build tools required.**

## 🚀 Running Locally

1. Clone or download this repository onto your machine.
2. Open the folder in **VS Code**.
3. Launch the project using a static server extension like **Live Server** in VS Code, or simply double-click `index.html` to open it directly in any modern browser.

## 📱 Deployment

FocusX is fully static and ready for instant deployment on platforms like:

- **GitHub Pages**
- **Vercel**
- **Netlify**

Simply push the repository files (`index.html`, `style.css`, `script.js`, and `README.md`) to a GitHub repository and enable GitHub Pages or link to Vercel.
